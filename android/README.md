# CloudlyRu Sync — Android-клиент

Служебное приложение: держит выбранные папки телефона в облаке CloudlyRu. Ставится как APK
(в Google Play не идёт — нужен доступ ко всем файлам, см. `../ANDROID.md`).

## Установка и первый запуск

1. Собрать и поставить APK (см. «Сборка на маке» ниже), либо взять готовый
   `android/app/build/outputs/apk/debug/app-debug.apk`.
2. Открыть приложение → выдать «доступ ко всем файлам», уведомления, отключить оптимизацию
   батареи (кнопки на главном экране).
3. Ввести адрес сервера и войти логином владельца с паролем — приложение само выпустит
   device-токен и сохранит только его (пароль нигде не хранится, токен можно отозвать в вебе,
   не меняя пароль).
4. «Добавить папку»: выбрать папку на телефоне (например `/storage/emulated/0/DCIM/Camera`),
   зону («Фото» или «Файлы»), папку в облаке (`Фото/Камера`) и срок хранения на телефоне:
   «всегда» — зеркало, «сразу»/«7 дн»/«30 дн» — выгруженное удаляется с телефона.
5. «Синхронизировать сейчас» — прогресс виден в уведомлении, кнопка «Стоп» останавливает.

## Что уже умеет (M3.1–M3.2)

- настройка адреса сервера и токена устройства (`ApiToken` из веба: Настройки → токены);
- список папок-задач: папка на телефоне → зона «Фото» или «Файлы» → папка в облаке;
- обход папки, SHA-256, дедуп до передачи байтов (`/sync/have` + `init` с хэшем);
- заливка частями прямо в S3 по presigned-ссылкам, продолжение после обрыва, ретраи с бэкоффом;
- догон журнала изменений сервера по курсору `seq`: удаления, переносы и закрепления доезжают;
- перезапись с оптимистичной блокировкой: если на сервере уже другая версия, локальная копия
  сохраняется как «(конфликт …)» и заливается отдельно;
- фон через WorkManager (периодика 15 минут) + короткий `dataSync`-сервис на «Синхронизировать сейчас»;
- аварийный стоп: если папка недоступна или скан внезапно пуст при известных файлах, проход
  прерывается без удалений;
- скачивание для файловых папок без вытеснения (зеркало вниз): временный файл → переименование,
  mtime восстанавливается с сервера;
- вытеснение по сроку с грейсом 10 минут и защитой закреплённого; состояние `вытеснен` не даёт
  скачать файл обратно или принять его за удаление пользователем;
- ограничение «только Wi-Fi» для задачи;
- экран состояния: сколько файлов выгружено/вытеснено, что в очереди и что не прошло.

## Чего пока нет (M3.3)

- шеринг в приложение из других программ (кнопка «поделиться» → загрузка в выбранную папку);
- ручное управление вытесненным («вернуть на телефон») и история вытеснений;
- переносы файлов между папками как `move` (сейчас переименование на телефоне выглядит
  как новая запись + удаление старой — содержимое не теряется, но id записи меняется).

## Сборка на маке

```bash
brew install openjdk@21 gradle android-commandlinetools
sdkmanager --sdk_root=/opt/homebrew/share/android-commandlinetools \
  --install "platform-tools" "platforms;android-35" "build-tools;35.0.0"
yes | sdkmanager --sdk_root=/opt/homebrew/share/android-commandlinetools --licenses
# путь к SDK задаётся в android/local.properties (в git не попадает)

cd android
JAVA_HOME=/opt/homebrew/opt/openjdk@21 ./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Релиз собирается `:app:assembleRelease` с ключом из `keystore.properties` (не в git): ключ
создаётся `keytool -genkeypair`, файл кладётся рядом с проектом.

## Что нужно на телефоне после установки

1. «Доступ ко всем файлам» — без него не видно корень Download и произвольные папки.
2. Разрешение на уведомления (прогресс и кнопка «Стоп»).
3. Отключить оптимизацию батареи — на агрессивных прошивках (Xiaomi/Huawei/Samsung) иначе
   фоновые задачи не запускаются, см. <https://dontkillmyapp.com/>.

## Журнал и диагностика

Состояние видно на главном экране: сколько операций в очереди, итог прошлого прохода, текст
последней ошибки. Логи приложения: `adb logcat -s cloudly-sync`.
